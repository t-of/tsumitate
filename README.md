# 積立投資シミュレーター — 毎月の積み立て、何年後にいくら

毎月いくら入れて、年に何 % ふえたら、何年後にいくらになるかを計算する。入れたお金とふえたぶんを分けてグラフにするので、長く続けるほどふえ方が大きくなるのが見て分かる。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/tsumitate/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 「毎月いくら」「年に何 %」「何年」のつまみ（スライダー・− / ＋）を動かす。動かすとすぐ、何年後にいくらになるかが出る。金額の数字をタップすると、ちょうどの額（100 円単位）を入れられる。
2. グラフの下の色が入れたお金、上の色がふえたぶん。グラフを指でなぞると、途中の年の金額が見られる。
3. 「上限 1,800 万円」をオンにすると、入れたお金の合計が 1,800 万円に届いたところで積み立てを止めて計算する。「いまの年齢」を入れると、年齢も添えて出る。
4. 右上の ？ に、計算のしかたと注意を載せている。

仮の条件での計算で、将来の成果を約束するものではない。特定の商品や投資のやり方をすすめるものでもない。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 計算のテスト（仕様の値の表・閉じた式・表示・入力・保存。フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `calc.js` | 画面に触らない中身。制度の数値 `RULE`、積み立ての計算 `simulate`、取り崩しの目安、金額の表示、入力の丸めと確かめ |
| `main.js` | 画面・操作・SVG のグラフ・効果音（Web Audio） |
| `test.mjs` | `calc.js` のテスト |

- グラフは自前の SVG。外のライブラリや CDN は使わない（オフラインでも動く）。
- 保存するのは `localStorage` の `tsumitate.inputs`（`{ v: 1, monthly, rate, years, age, cap }`）と `tsumitate.sound`（音のオン・オフ）だけ。
- 制度の数値（生涯の上限 1,800 万円・毎月の上限 30 万円）は `calc.js` の `RULE` にだけ書き、確かめた年月 `asOf` を添えている。制度が変わったらここと `asOf` を直す（画面の日付は `asOf` から作る）。
